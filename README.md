How to run the project:
Go to: https://marsoutpost-app.vercel.app/
Or
Open the live demo link to play in your browser. To run the source code locally, download the GitHub repository as a ZIP file, extract it, and open index.html in a modern web browser. No installation is required.

The live NASA DONKI space-weather data requires an internet connection. If it does not load when opening the local file, use the live demo link above.
